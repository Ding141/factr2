# 卸载后末端基线变化诊断（2026-10-10）

仅进行了只读检查，没有发送运动或修改运行控制参数。

事实：当前 q≈[-27.53,28.31,-1.18,-38.37,-0.08,-1.13,-8.15]°，控制目标 q_cmd≈[-27.68,28.29,-0.85,-39.37,-0.08,-1.00,-7.75]°。刚部署时目标为 [0,50,0,-55,0,0,0]°，目标和姿态均发生变化；这不能证明具体每次施力前后都发生了相同变化。

训练集最近实际位置样本的 J2/J4/J7 分别与本次快照相差约 21.6°/16.3°/7.9°。七维位置欧氏距离约 28.2°，仅作相邻数据覆盖诊断，不是已经定义的模型泛化阈值。训练主要为单关节大范围运动和中心附近末端20mm路径；逐关节边界检查不能保证所有组合姿态有充分训练覆盖。

当前推理 valid、100Hz，模型 stateless LSTM，每次使用100Hz×50帧历史。EMA alpha=0.2，无累计积分；输入稳定后滤波旧值约0.21秒衰减至1%。因此持续不同的稳定平台主要应检查输入状态、模型自由空间力矩偏差和机械摩擦/滞回，而不是认定滤波永久记住外力。

机械静摩擦和传动滞回、不同位置误差下的位置保持力矩属于待验证原因。模型使用 q、dq、q_cmd，理论上能学习这些输入对自由力矩的影响，但当前训练和短历史不保证充分覆盖卸载后的状态。

末端采用当前姿态雅可比换算，坐标为 right_attachment_point；姿态改变会改变映射和坐标方向。当前条件数约14.7，未达到100的奇异拒绝阈值。可用仅代表同步、范围、几何检查通过，不代表真实零接触精度通过。

后续应固定同一控制目标比较施力前与完全卸载静止后的 q/q_cmd/dq/实测力矩/预测力矩/残差；记录已知空载的多姿态静止、移动后停止和正反向接近同一姿态的数据用于独立评估与补充训练。未确认空载时不自动归零，避免把真实持续载荷扣除。
