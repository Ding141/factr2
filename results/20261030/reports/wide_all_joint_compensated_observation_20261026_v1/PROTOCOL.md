# 七关节全启用补偿的同轨迹观察

用户明确要求“对所有关节施加补偿，然后控制机械臂运动收集波形图数据”。沿用前次已确认的完全相同轨迹及速度/加速度/jerk、跟踪、CAN和数据年龄保护，不扩大运动范围。补偿仅进入外力矩观察输出，不进入电机命令，不修改重力补偿或控制器。

保持冻结NEXT均值与sigma，原补偿权重、滤波、限幅、支持域完全不变，只将补偿启用掩码由J1/J3/J5改为J1–J7全部启用。原验证掩码保留在selection及activation_override中。此次是用户预先指定的全轴研究对照，不宣称四个新增关节通过了原验证筛选。不重新拟合，不在线学习/自动归零，不使用力矩作为补偿特征。

全轴离线测试：相同滤波下高速RMS 0.51941→0.39094Nm；旧低速0.07725→0.09630Nm，回归未通过，deployment_ready=false。测试数据此前已用于评价，未据此挑选全轴掩码。在线逐帧与离线数值最大差约4.44e-16Nm。

分别保留NEXT原始残差、同输入同滤波无补偿对照、七轴最终输出、实际补偿量和运动学估计。另重放同一批数据的原三轴掩码以隔离新启用四轴的作用。越界帧保留标记，报告统计只使用预定正式段中间140秒的有效帧。

运动前核查校时仍暂停，并执行90秒静止时间与数据流验证；结束后确认无运动发布者、机械臂静止，现场恢复sudo systemctl start systemd-timesyncd。
