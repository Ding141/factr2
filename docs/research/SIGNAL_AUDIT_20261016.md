# 力矩、位置、速度与原生控制目标：离线信号审计

完成日期：2026-10-16（Asia/Shanghai）。全部计算离线完成，没有创建 ROS 节点，没有发布运动指令，也没有修改机器人、模型、反馈换算或在线滤波参数。

## 结论

1. 已记录的原生控制目标来源正确；没有发现把整段最终目标误当作逐周期目标的问题，也没有发现位置/速度之间的度与弧度倍数错误。
2. 软件侧可见的消息年龄为毫秒量级；位置导数与速度反馈之间只有 0–10 ms 的表观相位差。指令到实际运动约 130–210 ms 的等效跟踪滞后在独立日志中得到支持，但它包含机械、控制器和摩擦动态，不能被称为电机采样延迟，也不应因此把 NEXT 的当前跟踪目标随意前后平移。
3. 反馈量化明显。静止时速度有与半个量化步长接近的固定偏差和抖动；这种偏差可被一致训练的模型部分学习，单独存在并不能证明它就是假外力的全部原因。
4. 在线外力矩 EMA 确实带来低频约 40 ms 群延迟。它可以延迟瞬态，但不能解释长时间保持后的持续偏置。
5. 按训练数据冻结的小幅力矩平移在独立日志中只带来有限改善。当前证据不支持用固定时间平移解决整体空载误差。
6. 真实 CAN 接收至电机采样的绝对延迟、各关节硬件采样偏差以及 Nm 的物理绝对标定，现有日志不能唯一辨识；这些项保持“未知”，没有假设为零。

## 单位与信号来源

原始训练 H5 的位置、目标为 rad，速度为 rad/s，力矩字段按协议解释为 Nm。独立 CSV 中带 `_deg` / `_deg_s` 的列由记录程序从 rad / rad/s 转换而来，分析时已转回 SI 单位。时间戳全程用 int64 ns，避免 epoch 浮点精度损失。

适配器不重新估计力矩或速度：它取 `/joint_states` 的 position/velocity/effort，取 `/joint_position_controller/command_state` 的 position。后者在控制器的同一更新函数中与写入硬件接口的 pos_des 一起发布。该值是控制器输出目标，仍不是已确认在电机端执行的 CAN 指令；总线传输和协议量化之后的实际应用时间未记录。

依据诊断中的 command_source_stamp_ns 对原生 bag 做精确时间匹配，训练 98,254 行全部匹配；H5 目标与原生目标的最大差为 float32 舍入量级，最坏约 5.96e-8 rad。原生目标速度与目标位置导数的 RMSE 为 8.71e-6–2.64e-5 rad/s，支持目标位置/速度的单位和逐周期来源正确。

速度反馈与位置导数的训练拟合尺度为 0.965–0.996，独立数据相关性约 0.989–0.998；未发现 57.3 倍误差或整体符号反转。此项支持相对单位一致，不能代替外部角度标定。

本次核对的驱动、硬件接口和七个电机协议配置与采集元数据记录的机器人 Git 提交逐字节一致。这证明实现来源一致，不证明电机固件配置实际值或物理力矩常数已经标定。

- 原生控制目标头时间至 bag 存储时间：P50 0.097 ms，P95 0.141 ms，最大 1.922 ms；这个差值不能独立分解为网络、调度和存储延迟。

- 独立整段约 99.916 Hz，存在两处约 40 ms 的源时间间隔。一处位于段边界，所以 `validation.json` 的段内 cadence 计为一处；整段计数在 `supplementary.json` 为两处。没有补值，也没有跨缺口拟合相位。

- **速度相位：** 0–10 ms 处于 100 Hz 分辨率量级；独立改善最多约 1.55%，不足以支持大的时间错位假设。不能将 0 ms 估计解释为物理延迟恰好为零。

- **力矩相位：** 对冻结 NEXT 自由运动预测与实测力矩做相位诊断。J1–J4 的训练最小值为 0 ms，J5/J6/J7 为 -40/-10/-10 ms；独立改善仅约 4.28%/0.68%/1.42%，主要关节残差仍然存在。负值不可能被解释为负硬件延迟；它可来自模型相位、动态误差或滤波。不得据此宣布已标定力矩采样时延。
- 参数文件中保留了事件分组重采样的相位区间与完整训练损失曲线。它们仅表示所选信号/模型下的统计稳定性，不是硬件测时置信区间。

## 尚不能由这些记录辨识的项目

CAN 解码内部存有每台电机的 `last_update`，但发布 MotorState 时用发布时刻重新盖头时间，未导出每关节采样计数、CAN 接收硬件时间或反馈年龄；当前 bag 也未包含原始 CAN 或 `/joint_states`。电机内部的编码器/速度/电流滤波延迟、跨关节采样错位与缓存陈旧时间，因而不能与真实动力学唯一分离。

Nm 字段是配置量程解码后、按轴方向变换的反馈值，不是本日志里独立测得的关节输出力矩。没有原始电流、实际固件量程回读或已知力矩参考，故绝对比例和真实零点不能仅靠现有数据验证。

需要以后补充的观测是每关节反馈的接收时间/采样序号、CAN 命令发送时间、`joint_states` 原始消息及固件参数快照；若要验证物理力矩比例，还需已知载荷或独立传感器。这里仅列明信息缺口，本次未启动新的采集或运动。
