# 电流反馈、力矩准确性与 NEXT 残差：文献及本机证据

日期：2026-10-23。结论依据：现有代码、今天已关闭的实验日志、下列论文原文/出版方材料。本次只做离线分析，没有新增运动、改变保护、驱动参数或部署滤波。

## 1. 判断

电流测量误差可能同时造成“上报力矩不准”和“真实输出力矩脉动”。但目前持续数 N·m 的自由空间残差，不能仅凭曲线波动归因于随机电流噪声。本机还存在训练姿态之外运行、跟踪阻滞/释放、量化及绝对力矩比例未独立标定的问题。

必须分开验证三个问题：

1. 驱动测得的电流是否等于实际相电流/iq：需要独立电流测量。
2. 电流或协议力矩是否能准确表示输出轴力矩：需要输出轴力矩参考。
3. NEXT 相减后是否等于环境外力矩：需要自由空间及已知外力的独立验证。

三个层次不能相互替代。反馈很平滑不证明绝对数值准确；“空载”也不表示电机力矩为零，因为重力、惯性、摩擦和位置保持都需要力矩。

## 2. 本地实际收到的是什么

`dual_arm_robot/src/W3_ROBOT/w3_robot_bridge/src/damiao_protocol.cpp:189` 从 D[4] 低四位和 D[5] 解出 12 位 T 字段，按 YAML 的 torque 范围线性换算为名义 N·m。`dm_hardware_interface.cpp:624` 再乘关节方向符号，导出 effort；adapter 转发该值。当前链路没有独立的 ia/ib/ic、iq、ADC 原码、内部 iq_ref 或 PWM 时序记录。因此应称其为“驱动上报的名义力矩”，不能把它当成已由外部仪器验证的电流或输出轴力矩。

制造商 [DM-J4310-2EC V1.1 手册，第7、9–10页](https://files.seeedstudio.com/products/Damiao/DM-J4310-en.pdf) 将反馈 T 定义为力矩，给出 12 位映射；MIT 模式的 PD 与前馈之和进入电流环。这份手册不能证明本机各型号、硬件版本、固件的实际标定一致，需逐台核对。

|关节|本机名义映射范围|每个12位码对应力矩|
|---|---:|---:|
|J1/J2|±54 N·m|0.026374 N·m|
|J3/J4|±28 N·m|0.013675 N·m|
|J5/J6/J7|±10 N·m|0.004884 N·m|

计算为 `(max-min)/4095`。这只是通信量化步长，不是传感器准确度，也不是恒定的噪声标准差。不能只改 ROS 中 T_MAX 以提高分辨率，必须与电机固件的实际映射一致。还需确认上报值属于电机轴还是减速器输出轴，避免重复乘减速比；核对峰值/RMS 电流以及 dq 变换约定。

此外，发送的 `torque` 是 MIT 前馈项，电机内部还叠加 Kp、Kd 项；直接把“反馈力矩减发送 torque”当电流测量误差会混入真实伺服作用。

## 5. 建议的验证顺序

### A. 先核对量纲及全链路

对每台驱动冻结型号、序列号、固件版本、T_MAX/V_MAX/P_MAX、力矩常数、减速比、方向、反馈单位、温度。由厂商说明 T 是实际 iq 换算、滤波估计还是其他内部量；若允许，导出 ia/ib/ic、id/iq、iq_ref、电角度、母线电压及内部采样时间。

对同一批字节分别检查 raw CAN → bridge torque → hardware effort → adapter effort，验证换算、方向和时序。软件一致性只是必要条件，不能替代真实物理标定。所有读写驱动参数应单独规划，本次没有发送参数查询帧或改参数。

### B. 电流准确性：独立电气参考

在有机械固定/承托的测试台上，使用经校准、具有所需带宽的相电流探头或隔离分流测量。不要把电源输入电流当成绕组相电流或 iq，也不能把 iq_ref 当成真实电流。

如测 ia/ib，需使用正确电角度和一致的 Clarke/Park 约定计算参考 iq；同步比较相同带宽的数据。母线电流与相电流受 PWM、回馈和功率转换关系影响，简单相等会产生错误结论。

相电流正常随电角度周期变化，不能把整条交流波形都当噪声；对力矩更直接的是经正确变换的 iq，以及它相对于独立参考的误差。即便 `tau_e ≈ Kt*iq` 对电磁转矩成立，输出轴还涉及传动损失和惯性，且协议值可能已经包含输出侧等效换算，不能未经确认再乘一次减速比。

测试正负多个电流平台、重复测量和不同温度，拟合 `I_report = a*I_reference + b + e`，分别报告增益误差、偏置、残差 RMS/标准差、95%绝对误差、非线性/饱和及动态相位。仅有高相关系数或 R² 很高不够。

低频观测验证时，参考与驱动数据先按共同带宽低通，再比较；要看 PWM 纹波则仪器带宽与采样率必须覆盖实际 PWM 频率和关注的谐波，并考虑抗混叠。100 Hz ROS 日志不能完成此项验证。

若闭源驱动无法导出相电流/iq，就只能先做输出力矩黑盒验证，不能宣称已验证其电流传感器。不要在未支撑的机械臂上关闭保持控制来测“零电流”。

### C. 输出轴力矩准确性：独立机械参考

优先使用已标定的扭矩传感器；也可在合适夹具上用已知力臂与校准测力计/小载荷，计算沿关节轴的 `tau_ref = axis · (r × F)`。同时计入力臂、方向、传感器校准和温度的不确定度。

覆盖正负力矩、多个幅值和正反加载顺序，保持相同实际角度，记录升降载滞回。不能只看目标角度相同，因为当前存在到位偏差；也不能把一次静止挂载的差值都归因于 K，因为静摩擦可能承担载荷。慢速正反运动或独立输出轴传感器有助于区分摩擦、效率和比例误差。

拟合有效输出关系时允许偏置与方向/温度项，但参数辨识与最终验证必须用独立会话。电流准确而输出轴不准，优先考虑 K、传动效率、静摩擦、齿槽及弹性；不要靠滤波解决机械比例误差。

### D. 噪声对 NEXT 的实际影响

在模型训练覆盖内，用固定控制器及模型，分别采集静置、匀速、换向、启停，按姿态/速度/温度分组。已有异常未解决前不升级运动范围。

在无接触验证数据上报告残差均值、标准差、分位数、PSD及误报次数/小时；在带独立力参考的数据上报告力矩 RMSE、增益、延迟、弱接触漏检率。对于已知接触位置，参考关节外力矩用 `J_contact(q)^T * wrench_reference`，统一坐标系和正负方向；不需要反求 Jacobian 逆。

做离线逐项消融：保留原始数据，对力矩测量、速度输入、时延分别注入已知误差，固定其余量及模型。在 q/v/command 输入固定时，NEXT 不将当前 measured torque 作为自由力矩预测输入，因此测量力矩加多少扰动，原始残差就加多少扰动。此检查只能验证算法敏感度，不能证明真实硬件存在同样误差。

如果低通后方差降低但偏差仍在，优先排查尺度/模型；若变化与电角度、PWM 或参考电流误差同步，才支持电气原因；若与跟踪误差积累、停滞后释放和换向相关，则还需检查机械与伺服。闭环相关性本身不构成因果证明。

## 6. 按结果采取措施

|验证结果|对应措施|
|---|---|
|电流有零偏/增益/温漂|驱动侧校准、厂商支持的补偿，或经验证的温度模型；校准后保留版本记录。|
|电流环里有开关干扰/采样误差|检查采样窗口、模拟抗混叠、接地/屏蔽与电源；由驱动侧处理，必要时更换可校准驱动。|
|上报量化或主机降采样失真|固件提供更高分辨率/更高频反馈，或在降采样前滤波；不擅自改变协议量程。|
|随机高频波动为主|按已知接触带宽选择因果低通/Kalman，并同时验证幅值、延迟、漏检和误报；保留原始流。|
|静摩擦/传动/伺服阻滞|先解决跟踪问题，再固定控制器采集；平滑曲线不能证明实际脉动消失。|
|NEXT超范围或模型失配|先按有效范围评估；底层信号/补偿改变后重新采集训练与独立验证，不用在线清零掩盖偏差。|

建议先为 J3 做电气与输出轴对照，再对 J7 检查保持误差和释放脉动；三种电机型号都要有代表性验证，最终每个关节保留校准记录。若目标是可靠识别0.1 N·m级接触，就应据该任务制定误差预算与独立参考精度，而不是以“曲线看上去平滑”为验收条件。
