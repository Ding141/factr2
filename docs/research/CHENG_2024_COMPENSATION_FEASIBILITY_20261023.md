# Cheng 2024 电流补偿用于本机外力检测的可行性

结论：**作为驱动侧电流测量校正，有条件适用；现有100 Hz ROS力矩接口不能直接复现。不能用NEXT残差的在线积分归零代替该方法。**

依据：[原论文，Sensors 2024, 24:1538，Sec.3及4](https://www.mdpi.com/1424-8220/24/5/1538)。论文在电气模型下估计相电流偏置，再参与FOC闭环补偿；需要电流、电压、电角度/速度及电机电气参数。其人工偏置实验不能代替本机接触力矩验证。

## 当前接口的实际限制

- `dual_arm_robot/src/W3_ROBOT/w3_robot_bridge/src/damiao_protocol.cpp:189`：解码12位T字段为名义力矩，未解出相电流或iq。
- `dual_arm_robot/src/W3_ROBOT/w3_robot_bridge/include/w3_robot_bridge/motor_types.hpp:115`：本地反馈结构没有电压、相电流或电角度通道。
- `dual_arm_robot/src/ieir_controllers/src/dm_hardware_interface.cpp:624`：力矩乘方向后成为effort。
- `factr2_next/src/factr2_next/factr2_next/inference/inference_node.py:293`：NEXT执行measured减自由力矩预测；随后才做EMA/低通。

论文所需的αβ电流、电压无法从一个T标量唯一恢复。关节角也不能未经电机减速比、磁极对数及零角标定直接代替电角度。提高ROS发布频率不能恢复未上传的量。本仓库检查范围内没有实现该电机的内部FOC固件；厂商能否开放或协助修改仍未知。

## 应该放在哪里

```text
相电流ADC → 电流偏置估计/校正 → FOC电流环
                         ↓
               经验证的电流/名义力矩反馈
                         ↓
             ROS/adapter → NEXT → 外力矩
```

这是建议集成位置，非本机当前已具备功能。驱动端还需确认上传T使用校正前还是校正后的电流，以及它是测量值还是内部估计/参考量。若控制环已校正而上报仍沿用旧量，窗口结果未必改善。

|可选路径|判断|
|---|---|
|厂商支持在FOC内补偿|可考虑，先做单电机台架验证，再做整机验证。|
|可导出同步电气遥测，先运行只读观测器|适合评估；离线算得偏置不等于已消除真实力矩脉动。|
|只在现有NEXT节点中加入同名PI模块|缺少原方法输入，不能称为论文复现。|
|对NEXT残差做慢变偏置自适应归零|不能用于保留持续外力的测量；会混淆偏置与真实接触。|

## 为什么残差归零会损失真实外力

用简化误差模型说明：

`r = tau_external + bias_electrical + error_free_model + noise`。

仅从r看，持续的真实外力、驱动偏置、自由模型偏差可以有相同观测结果。若设置 `b_hat_dot = gamma * (r - b_hat)`，再输出 `r - b_hat`，只要r持续不变，校正结果最终都趋于0，包括真实恒定外力。这是把电气偏置观测错误移植到机械残差后的结果，并不是原论文必然会抹除接触力。

原方法有额外的电气模型及测量信息；真实负载会改变真实电流和电压，理论上可以与测量偏置区分。但模型不准、时序不一致、逆变器非理想或温漂，也可能被错误解释为偏置，需要独立参考验证。

## 对本机可能有效和无效的部分

可能改善：经独立证据确认的电流通道偏置及其引起的电流环脉动。

不能指望单独解决：力矩常数/输出轴尺度、12位通信量化、减速器摩擦与滞回、位置阻滞、反馈时序、NEXT训练范围之外的预测。它也不是一般随机噪声的通用消除器。

本机已记录静止J2反馈标准差约0.0078 N·m、残差均值约−5.643 N·m，且NEXT为out_of_scope。不能把该均值当成待补偿的电流偏置直接减去。J3反馈标准差约0.0408 N·m，可优先独立测量，但现有数据尚不能分离真实伺服力矩与传感噪声。

## 采用前应完成的验证

1. **确认可接入。** 获取厂商对相电流、同步电压/电角度、采样时序、T字段定义及FOC补偿接口的说明；明确本机电气参数和温度依赖。缺少这些信息时暂停原方法的移植，继续做输出力矩黑盒标定。
2. **先做单电机只读评估。** 用独立相电流参考和输出轴力矩参考，在可靠固定/承托的台架上覆盖零速、低速、换向、正负负载和温度。分开检查电流误差与真实输出脉动。
3. **证明没有损害接触测量。** 在独立会话施加已知且持续的外力矩，检查校正后稳态力矩不会逐渐回零，同时评估增益、RMSE、延迟、弱接触漏检和自由空间误报。
4. **处理NEXT的一致性。** 采集记录必须包含补偿版本/状态。不能只修正在线measured而沿用旧目标定义。FOC行为或测量定义改变后，重新验证自由模型，必要时重采训练；原日志保持为独立证据。

实施顺序建议：先排查当前模型超范围和底层跟踪，再确认J3是否确有电流测量误差；若厂商支持电流环改动，再考虑移植。若只能使用当前CAN反馈，已知载荷/力矩传感器标定以及经过验证的滤波，比在NEXT残差上增加PI更有依据。

此文为可行性分析，未发送真机运动或修改在线补偿。
