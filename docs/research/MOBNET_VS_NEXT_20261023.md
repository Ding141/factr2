## 1. 结论

MOB-Net最有价值的参考是“动力学观测器与可学习误差分开”“对误差输出分布”“按任务覆盖采集并验证接触”，不是简单将LSTM换成GRU。

对本机建议依次做：信号/跟踪与覆盖核查；在原NEXT上做均值-方差输出的独立消融；再用同一批数据比较MOB及MOB+GRU。暂不把完整人形机器人框架直接搬到七关节固定基座右臂。

## 2. 核心技术路线

### 2.1 动量观测器提供基础残差

论文第4–5页，式(4)–(11)，定义广义动量 `p = M_nom(q)*qdot`，通过积分形式的动量观测器得到残差r，避免直接数值求关节加速度。理想模型下每个通道具有一阶低通关系 `r_j(s)/tau_e,j(s) = k_j/(s+k_j)`。

真实模型中，论文式(15)为：

`r = filtered(tau_external) + filtered(tau_uncertainty)`。

不确定力矩包括动力学参数误差、摩擦与传感噪声。故普通MOB也会在无接触时产生非零残差。论文不是认为“只要加MOB就有准确外力”。

### 2.2 GRU学习不确定力矩，而非全部外力

论文第5–9页，网络从状态历史估计不确定力矩的均值mu_u和方差var_u，最终输出：

`tau_external_hat = r - mu_u`。

这保留了MOB中的物理响应路径，同时学习可预测的模型/摩擦误差。输出仍有MOB的滤波和延迟，并非无延迟真实外力。论文第11页图6明确采用同带宽滤波的真实力矩作部分比较，评估时不能漏掉这点。

论文认为独立随机传感噪声无法逐点推断；学习可以减少系统性误差，但不会恢复已经丢失或被量化的信息。

### 2.3 利用动力学结构拆分网络

第6页图2、第7页表1：按虚拟关节、左右腿、腰、左右臂分六个GRU-Linear网络，输入选取与该组动力学相关的状态。

腿部输入包括关节位置/速度、期望力矩和基座IMU信息；手臂输入为自身关节、腰部关节和基座IMU，不直接加入期望力矩。作者对上肢忽略负载相关摩擦，这是任务假设，不能自动套用到本机减速器。

对固定基座单臂，可先保留七关节联合模型；没有必要引入人形六模块和虚拟基座。也不能随意拆成七个完全独立的单关节网络，忽略串联机械臂的耦合。双臂是否独立还取决于基座和是否共同操作物体。

### 2.4 训练标签取决于是否已知真实外力

表1及Sec.4.2.3：

|身体部分|训练时的接触状态|原文目标|
|---|---|---|
|上肢/腰|无外部接触|r|
|腿与虚拟关节|行走，存在地面接触|r减去FTS提供的参考外力矩|

因此，上肢自由运动路线适用于无额外力传感器训练；原论文完整人形方案的腿和虚拟基座训练依赖足底FTS。不能仅凭标题“sensorless”认为训练也完全不用FTS。

表1将接触标签写为r减参考外力矩。移植时必须核对两条信号的时间戳、滤波和传感延迟，不能自行认定原始FTS已与MOB同相位。

### 2.5 高斯分布学习与异常检测

式(18)–(22)：每个关节独立建模为高斯分布，输出均值及方差，用softplus保证方差为正。忽略常数的损失为：

`L = sum_j[log(var_j) + (y_j - mu_j)^2 / var_j]`。

网络输出的sigma不是“电机电流准确度”，也不自动构成校准的95%区间；它描述给定输入下训练目标的条件离散程度。高斯、关节间独立等都是假设。

Sec.5.3采用两个报警通道：外力矩均值超阈值，或不确定力矩标准差超阈值，二者用OR组合。高sigma在这里也是异常线索，不能简单理解为“把这段外力忽略掉”。

### 2.6 数据覆盖和随机力矩探索

Sec.4.3和6.2：随机动作覆盖位姿，改变速度/任务条件，并通过Random Torque Exploration扩展速度-期望力矩分布。其训练采样1000Hz、控制2000Hz；表1的50/100步是TBPTT范围，不能直接等同本机100Hz下的50帧滑窗。RNN状态是否跨片段保留也必须在实现中明确。

对本机可借鉴“扩展状态与伺服努力的覆盖”，不直接照搬随机力矩注入。当前已有低速阻滞/释放和速度保护事件，应先排查这些问题。后续采集需要核对真实运动，不以规划速度/加速度替代实测覆盖。

## 3. 与NEXT的结构对比

|项目|NEXT/本地原版|MOB-Net|
|---|---|---|
|被学习的量|自由运动时会观测到的力矩|动力学观测器中的不确定力矩|
|最终估计|measured减自由力矩预测|MOB残差减不确定力矩均值|
|动力学模型|估计器不要求显式M/C/g|MOB需要名义动力学|
|网络|本机2层LSTM，7输出|分组GRU，输出均值和方差|
|本机输入|q、qdot、q_cmd-q历史|原文按身体分组选择q/qdot、基座IMU及部分期望力矩|
|损失|物理N·m尺度MSE|高斯负对数似然|
|训练标签|自由运动中的measured torque|无接触用r，有已知接触用r减参考外力矩|
|时序|本机100Hz、50帧、stateless滑窗|原文1000Hz数据、TBPTT训练|
|主要工程成本|干净、覆盖充分的自由运动数据|除数据外还需动力学和观测器实现、滤波时序与驱动力矩一致性|

两者都保留“测量/观测器减去背景预测”的结构。NEXT不是直接从状态回归外力的FTS-e2e。因此，MOB-Net优于论文FTS-e2e的证据不能直接作为优于NEXT的证据。论文没有进行MOB-Net对NEXT的直接实验。

正负号也必须统一：MOB-Net式(3)写为名义动力学减驱动力矩，NEXT式(1)写为驱动力矩减自由动力学。照搬公式前必须明确外力表示环境对机器人还是机器人对环境，不能直接比较未统一符号的曲线。

## 4. 论文结果说明了什么

|原文位置|结果|解释边界|
|---|---|---|
|表7，第13页，真实左腿正常行走|平均RMSE：MOB 21.987、MOB-Net 2.602、FTS-e2e 2.232 N·m|学习校正大幅改善MOB；MOB-Net并非所有正常工况精度最好。|
|图10，第14–15页，4次摆动膝碰撞|LL3平均RMSE：MOB-Net 6.576、FTS-e2e 13.207 N·m|支持该接触工况下的鲁棒性，不代表跨机器人精度比较。|
|表9，第16页，60次腿部碰撞|OR检测60/60，平均延迟11.90ms；mean 53/60；sigma 58/60|两个通道互补；不是形式化安全保证，也不是弱接触精度证明。|
|表11，第19页|移除RTE后该膝碰撞RMSE由6.576增至13.431 N·m|数据覆盖与网络选择同样重要。|

Sec.5.3碰撞峰值约100–200N，Sec.5.4明确弱小力敏感性需要更多实验。本机检测轻微外力不能直接沿用这些阈值和延迟数字；100Hz数据每帧约10ms，1kHz实验的5ms连续过滤策略也不能原样照搬。

最关键的局限在第21页Sec.8.2：OOD主要指力矩维度的新接触，位置和速度仍在训练分布中；作者未验证关节位置/速度超范围的泛化，也没有给出该泛化的理论保证。

## 5. 对本机的参考价值，按优先级排序

### 优先级1：先把大残差分类

把可学习的系统误差、瞬时随机波动、模型超范围、数据链路异常分开。现有记录显示J2/J4近零姿态超训练范围，不能当成模型分布内精度评估。J3力矩波动及J7阻滞/释放应单独诊断；换网络不能取代电流/输出轴力矩标定。

当前模型metadata的包络只是训练位置的矩形界，连界内所有组合姿态都没有认证；模型仍标为readonly_trial、deployment_ready=false。MOB-Net的OOD结果不能用来解除该限制。

### 优先级2：先为原NEXT增加均值-方差输出消融

建议作为新分支实验，保留现有基线不变：

`NEXT-U: history(q,qdot,qcmd-q) → (mu_free, var_free)`

`external_hat = measured - mu_free`。

这是借鉴分布学习的本机改造，并非完整MOB-Net复现。保持数据、网络容量、历史、归一化和划分可比，先判断NLL头是否优于原MSE。若目标归一化，输出方差恢复物理量时乘y_std的平方，而非一次方。

将力矩值、状态适用性和不确定度分开显示。sigma必须用独立会话校准覆盖率，最好包括已知外力的持续加载、卸载、碰撞和无接触异常；只在自由空间校准不能证明接触时同样可靠。

不要只用abs(torque)/sigma作为唯一报警值：碰撞时sigma可能升高，反而使这种比值下降。也不把高sigma直接解释成碰撞，它还可能来自机械异常或数据异常。

### 优先级3：建立完整的MOB+学习校正对照

对固定基座右臂，用同一冻结URDF、驱动力矩定义和采样时间建立纯MOB，在独立自由运动数据上检查r，再训练7关节联合GRU学习r的均值/方差，最终r减均值。此训练可以借鉴论文上肢方式，无需训练用接触标签；最终绝对精度验证仍需外部参考。

这是一条新的估计管线，不能把MOB再从NEXT输出减一次，也不能随意对两个估计器加权而忽略符号、延迟和误差相关性。

实施前特别需要核对：

- 本机MIT命令的torque是前馈项。总驱动请求还包括电机内部Kp/Kd项，不能把该字段直接当成论文的全部期望关节力矩。重建总请求只能作为经验证的近似，不能代替实际电流/力矩校准。
- 论文假设期望与实测力矩误差较小，本机存在阻滞和量化，必须重新检查该假设。
- 动量观测器离散化、增益、初始化、时钟回退、断流重置和滤波标签需按100Hz设计，不能复制1kHz的参数后认为等价。
- 继续以关节外力矩为主评估。MOB-Net也不能恢复Jacobian秩缺失的信息；高精度关节估计并不保证任意接触点的末端力可逆求解。

### 优先级4：有针对性地扩充数据

待跟踪问题解决后，采用受限、已检查的动作，覆盖单关节/联动、正负方向、匀速/启停、多个实际姿态及温度。记录真实到位状态和历史，检查同一实际姿态从不同方向到位时的残差。

保留原始CAN与四路NEXT输入，按整会话、日期和任务划分；新标定/调参仅用训练或专门标定集，最终新测试会话独立。已有查看过的历史日志适合诊断和回归，不再宣称全新盲测。

## 6. 建议的最小实验矩阵

|组别|目标|用于回答|
|---|---|---|
|A 原NEXT|现有MSE自由力矩模型|基线表现|
|B NEXT-U|相同历史，均值/方差输出|分布学习是否改善可靠性与误报评估|
|C 纯MOB|名义动力学观测器|显式动力学及滤波自身的误差/延迟|
|D MOB+GRU|学习C的不确定力矩|物理观测器加学习校正是否值得新增复杂度|

统一比较：逐关节bias、MAE/RMSE、误差P95，按静置/运动/换向/温度分组；已知外力的增益、延迟、持续力保持及卸载恢复；自由空间误报次数/时间；模型适用率；不确定区间覆盖率与宽度。不能仅凭训练loss或一张空载归零曲线评优。

补充澄清：现有NEXT+MD中的MD是Motion Discriminator，来源于另一篇工作，不是MOB/动量观测器。已有MD特征消融不能当作MOB-Net对照；单seed结果不支持盲目添加特征或更换架构。
