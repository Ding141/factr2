## 1. 摩擦补偿已生效，但不提供静止支撑力矩

捕获配置为`friction_compensation_enabled=true`、`smooth_friction_enabled=true`。参考速度来自`/joint_position_controller/command_state`，过渡速度0.01 rad/s，参考超时50 ms，力矩变化率8 Nm/s，力矩上限0.8 Nm。

启用的分支是：

```text
tau_f = gain * [tanh(v_ref / 0.01) * Coulomb(direction) + viscous * v_ref]
```

达到零规划速度后前馈退回零；静摩擦剩余负载由位置伺服承担。`friction_deadband=0.05 rad/s`属于未启用的旧分支，不能据这个参数断言当前0.6°/s运动没有摩擦补偿。参数覆盖数组中的0表示继承电机型号系数，也不表示把该关节补偿关掉。

匀速平台中，两批日志独立得到相同结果：

|关节与方向|记录命令减去带增益的重力 (Nm)|代码理论前馈 (Nm)|
|---|---:|---:|
|J1/J2，+0.6°/s|+0.2603|+0.2603|
|J1/J2，−0.6°/s|−0.2745|−0.2745|
|J4，−0.6°/s|−0.3521|−0.3521|
|J4，+0.6°/s|+0.3713|+0.3713|

平台重建误差在浮点精度量级。静止最后1秒的该差值也退回近零。因此当前问题不是“开关没有生效”，而是按型号加载的动摩擦、黏性系数及`tanh`平滑未必能描述装机后的静摩擦、齿槽和热状态。文件中的`static_pos/static_neg`没有被当前运行分支加载为起动力矩。

另一个需单独审查的设置是J6：正负库仑系数均覆盖为0.45 Nm，而原DM4310型号值约0.0934/0.0990 Nm；这是约4.5–4.8倍的系数覆盖，不是整机摩擦标定结果。本轮没有取消该设置或用测试集重新拟合它。

## 2. 超出位置量化范围的阻滞明确存在

|实例|同一反馈位置码持续|期间目标位移|位置码数|反馈力矩变化|名义Kp误差力矩增量|
|---|---:|---:|---:|---:|---:|
|完整实验，J4 +0.6°/s|0.983 s|0.590°|27.0|+0.602 Nm|+0.618 Nm|
|现场曲线实验，J4 +0.6°/s|1.546 s|0.927°|42.4|+0.998 Nm|+0.971 Nm|

位置一个码为0.02186°，0.6°/s目标走过一个码只需约36 ms，上表停滞远超过这个量级。此时目标和速度参考仍在继续，前馈基本恒定，反馈力矩随位置误差积累。这更符合阻滞/静摩擦一类负载与伺服共同作用，而非仅由上位机目标停顿或位置量化造成。

为避免把码跳变都称为运动，分析预先采用描述规则：同一位置码至少0.10秒，且目标走过至少4个位置码。完整实验检测113段，其中79段在随后150 ms沿目标方向至少前进2个码；现场实验为27段，其中16段满足释放条件。最长J4停滞结束后的150 ms只前进约一个码，不满足该释放判据；“最长停滞”与“明显释放”没有混为同一事件。

这里没有识别机械回差宽度或静摩擦系数。要唯一分开摩擦与固件死区，需要额外观测电流/内部控制状态或独立位置反馈。

## 3. 速度量化与物理死区需要分开

软件编码采用16位位置、12位速度、12位前馈力矩。以下为按捕获标定方向还原的命令空间结果：

|关节|速度一个码|请求+0.6°/s|请求+1.2°/s|请求+2.4°/s|
|---|---:|---:|---:|---:|
|J1/J2|1.259°/s|+0.630°/s|+0.630°/s|+1.889°/s|
|J3/J4|0.560°/s|+0.840°/s|+1.399°/s|+2.519°/s|
|J5/J6/J7|1.399°/s|+0.700°/s|+0.700°/s|+2.099°/s|

0并不是这种对称偶数码映射中可精确表达的浮点值。当前编码的零目标也落在半码上；这说明命令量化值得核实，不证明电机内部真实零速一定偏置。内部速度与反馈打包速度可能有不同精度和定义。

J1的半速度码乘Kd量级约0.030 Nm，一个位置码乘Kp量级约0.0267 Nm；这些量级本身不足以解释J4停滞期间近1 Nm的力矩积累。两类问题同时存在。

没有在上位机原生位置控制路径中发现“位置误差小于某阈值就不动”的处理；电机内部的误差死区仍未知。不能通过只修改ROS中的`velocity_max`来提高编码分辨率：必须先确认对应电机固件量程，并保持两端一致。

## 4. J2稳态误差混有额外重力前馈

捕获的J1/J2重力系数是1.15，J7是1.1，其余右臂关节为1.0。J2回到50°目标后，实际约50.714°：

```text
额外重力前馈 = (1.15 − 1) * g_URDF(q) ≈ +0.825 Nm
名义位置PD  = 70 * (50 − 50.714) * pi/180 ≈ −0.872 Nm
```

额外前馈对应的静态位置偏移量级约0.676°，接近观测偏差。该机制在两批日志中重复出现，应优先与摩擦分开核查。1.15可能原本用于弥补质量/重心模型误差，所以本轮没有直接将其改回1.0。

J4的重力系数为1.0，但到位后仍有约−1.07°与+0.39°的目标−实际误差。两个端点目标不同，不能直接把这两个数相减称作同姿态滞回或机械死区宽度。当前证据支持摩擦/阻滞相关性，仍需同实际姿态、不同来向验证。

## 处理顺序

1. **先核实量程与零码。** 对照电机实际固件配置确认位置、速度、力矩量程和MIT解码定义；增加真实TX或驱动发送记录，和现有RX日志核对。保留原始码值，先不对NEXT在线输入单独减均值。
2. **分离重力与静摩擦。** 在多个姿态做正反方向到位并停留，按实际位置匹配后检查J1/J2重力系数；目标相同不等于实际姿态相同。不要使用本批独立日志拟合新时延或补偿参数。
3. **优先处理J4的阻滞。** 保持已验证的运动限制，单关节、分段标记启停，记录温度和可用的电流/内部误差；分别验证动摩擦前馈、静止保持误差及释放脉动。静摩擦、齿槽、线束或机械阻力尚不能凭现有传感唯一分开。
4. **信号与底层控制固定后再重训NEXT。** 增益、重力、摩擦或编码定义改变都会影响模型输入与自由力矩分布，必须另采训练和验证数据；当前两批数据继续保留作独立测试。

本轮没有准备或执行“直接增加起动力矩/提高Kp”的真机修改。现有跟踪脉动说明这种调整需要单因素、受限运动验证，不能靠把输出滤平来确认问题解决。
