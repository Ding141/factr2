# 原版 NEXT 加速度配对试验

本轮用户明确授权规划、执行机械臂运动并打开原版外力检测。试验目录为 `log/next_inertia_trial_20261016_v1`；原始会话为 `data/quick_capture/right/20261016_231752_162269`。原版末端页面为 http://127.0.0.1:8082/，模型、滤波、接触门限和控制增益保持原值。

## 冻结设计

- 四条关节空间路径：J1正向、J2正向、J4负向，以及J1/J2/J4按1/0.5/−0.5联动。每次单程标量行程6.144°。
- 七阶段S曲线，峰值速度固定3.84°/s，峰值加加速度固定25°/s³，峰值加速度4/6/8°/s²。改变加速度平台时长与匀速时长，保持几何路径和峰速一致。
- 各路径各档3次往返，方向分开分析；三轮条件顺序为4/6/8、6/8/4、8/4/6，路径顺序也交错。每个端点静置2秒，首末各10秒基线。
- 左臂保持冻结姿态。原生轨迹整段一次下发；Python不逐帧发送插值指令。
- 本轮计划153块、约385.32秒命令时间。已完成2302个离散配置的URDF碰撞检查；该检查不包含外部线束和环境障碍物。

运动仍使用既有独立guardian、反馈健康检查、实际跟踪限幅和有界停止，不修改其阈值。`STOP_TEST` 文件可请求本试验正常停止；不要停止机器人控制器来停止观测。已执行会话不自动重试，不重复运行目录中的 `run.py`。

## 实际运动匹配条件

在读取本轮结果前已冻结：同路径/同重复/同方向的三档实际峰速最大/最小≤1.15，实测起止姿态跨档跨度均≤0.3°；实际峰值加速度递增且高/低≥1.4。实测位置采用固定SG21、SG31两种离线求导，两者都需通过。原始反馈不被覆盖，不拟合或改变延迟，不将原生目标加速度当作实际加速度。

主指标为全部运动样本的关节力矩残差；末端力统计另附有效率，无效输出不补零。未匹配组仅列描述统计，不用于宣布惯性的因果贡献。CAN名义温度用于检查时间漂移，未作独立温度标定。

本轮第一段比较紧随探测，没有标准两秒前置静置，因此将其对应三档组标为历史不一致。原生成源码保存在实验目录的 `protocol_source.py`；后续生成器已补上探测后的两秒保持，不改变本轮冻结轨迹或执行记录。

## 代码及结果

`scripts/w3_inertia_protocol.py` 只负责规划及只读获取姿态；实际执行仍由既有采集/监护流程负责。`scripts/test_w3_inertia_protocol.py` 检查同路径、同峰速、同峰值加加速度、不同加速度、零速边界、往返一致、完整计划序列化、平衡重复及探测后静置。

本轮结果见实验目录的 `REPORT.md`、`analysis.json`，逐段实测速度/加速度和匹配原因都保留。该会话用于独立诊断，不加入训练；模型和原始数据不会因分析被修改。

本轮已完成153/153块、72段比较运动，NEXT记录49489帧。原生位置目标重建最大差约0.000143°；模型与实际控制配置哈希均保持一致。24组三档对照均未通过预定的实际加速度分离条件，故不能确认或否定惯性的因果贡献。所有路径的残差也没有统一的递增趋势。位置求导的峰值存在方法敏感性，结果要求先核查反馈/求导及跟踪，再开展新的独立验证，不能通过放宽标准改称有效对照。
