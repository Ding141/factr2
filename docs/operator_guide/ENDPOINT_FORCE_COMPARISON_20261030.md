# 新旧模型窗口中的末端受力曲线

8082（旧共享 LSTM）和 8083（新独立 LSTM）保留原关节力矩图，下方增加 Fx/Fy/Fz 及可勾选的合力 |F| 图。
单位 N，页面显示两位小数；记录仍为完整精度。作用点和坐标轴均为 `right_attachment_point`。

两个模型的同帧滤波关节残差，经相同实时关节姿态和 URDF 雅可比换算。沿用现有
`estimate_wrench` 六维阻尼最小二乘，再旋转到末端坐标系；图中仅展示力分量。
这是假设全部外载作用于末端的等效力估计，不是独立力传感器测量，也不适合把任意连杆接触解释为真实末端力。

保持原条件数上限 100、相对拟合残差上限 0.35、阻尼 0.005 和特征长度 0.4m。
训练范围外、几何近奇异、残差不满足末端载荷假设、URDF 不匹配或数据超过250ms时，末端当前值为“—”，对应曲线留空。
末端换算失败不清除关节残差或将其归零，不修改模型、重力/摩擦控制器、轨迹或补偿设置。

实现入口：`scripts/observe_w3_model_comparison.py`，默认加载
`config/w3/right/endpoint_force_comparison.yaml`。计算和发布频率为10Hz，历史保留100点；模型推理仍为100Hz。
网页快照在原字段之外增加 `endpoint_force`，包含状态、坐标系、力分量、条件数和历史。
数据话题为 `/next/right/model_comparison/endpoint_force`，记录器额外保存 `endpoint_force.jsonl`，包括两个模型的来源时间戳和有效性。

已验证：真实机械臂几何的已知载荷、坐标旋转、不可辨识/不符合末端假设时拒绝输出、旧新独立有效性、过期留空；
隔离 ROS 域199的同帧双模型、两个网页面板及断流复位；原关节力矩页面回归和页面脚本语法。
现场只读检查时，当前接近零位的 J2/J4 超出采集范围，条件数约118，末端图正确留空。
未为展示曲线而移动机械臂，运动仍需原任务的现场确认及暂停校时。
