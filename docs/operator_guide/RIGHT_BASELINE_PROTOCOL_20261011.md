代码方案随后经用户批准开始真机采集。2026-10-11 首次完整采集在快速 J1 段因跟踪误差超过 3° 中止，模型训练尚未开始。恢复采集保留六段完整慢速激励，补录有反馈中断的 J4 慢速段和全部后续动作；快速上限从 20 降为 12°/s，加速度从 80 降为 36°/s²。标定、控制器增益及在线保护阈值不变。原始失败会话和日志保留。当前唯一旧模型仍在 `/home/venom/factr2/models/w3/right/c2_20261010/`；新候选不自动部署。

## 依据与目标

参考 [FACTR 2 项目](https://jasonjzliu.com/factr2/)、[论文第 4 节与附录 A](https://arxiv.org/html/2606.12406v1)、[项目链接的官方代码](https://github.com/philiphan0109/factr2_next)。NEXT 学习无外部接触时的电机力矩，再从实测力矩中减去预测值。训练信号为位置、速度和命令位置误差的历史；逐关节与笛卡尔式联动、慢速与快速运动是论文的采集建议。

本方案保留上述模型和监督方法。增加静止、多方向返回、独立会话与卸载验收，是针对本机问题的工程扩展；不是论文报告过的自动归零算法或 W3 精度保证。

| 问题 | 采集和验证安排 | 达标依据 |
| --- | --- | --- |
| 空载仍有力/力矩 | 多姿态空载静止，每段 10 s；包含运动前、运动后和最后的参考姿态 | 每关节偏差、P95、整体 RMSE；末端各轴偏差、P95、可用率 |
| 松手后基线改变 | 无接触时从两方向返回同一姿态；另外录制手推/卸载验证 | 按实测姿态匹配比较基线差；卸载后独立检查偏差和漂移 |
| 经常提示奇异 | 多姿态与末端路径每个命令采样点检查缩放雅可比条件数 | 规划上限 20；在线仍用 100，不放宽在线门限掩盖问题 |

理论上的空载外力为零，但电流噪声、摩擦、回差、温度和模型误差使估计值只能接近零。不能把“完全无载荷”简单等同于“模型输出必须逐帧严格等于零”。如果同一位置、速度、命令误差的最近 0.5 s 历史相同，但内部预紧/温度导致不同保持力矩，论文这组输入可能无法唯一确定力矩；增加数据不能保证消除这个歧义。验收失败时应继续检查电流力矩比例、标定、机械与热状态，再决定是否研究更长历史或额外状态；这类改动需与论文复现分开比较。

## 采集动作

配方：`/home/venom/factr2/config/w3/motions/right_baseline_protocol.yaml`。
生成器：`/home/venom/factr2/scripts/w3_baseline_protocol.py`。

1. 平滑接近参考姿态 `[0, 50, 0, -55, 0, 0, 0]°`，静止 10 s。
2. J1～J7 分别覆盖已配置范围，依次完成慢速、快速连续正弦运动；限制速度为 6/12°/s，加速度为 24/36°/s²，默认 jerk 上限 120°/s³。
3. 回到参考姿态静止 10 s，便于检查采集前后基线。
4. 在 3 个条件良好的姿态分别从低方向、高方向返回并静止 10 s；每个姿态执行 XYZ 往复和 XY 圆形的慢/快末端路径，之后再次静止。
5. 平滑返回上述参考姿态，最后静止 10 s。不会自动回到直臂零位。

范围沿用之前扩大的工作范围，未再次增加：J1 `[-135,105]°`，J2 `[-0.5,155.4]°`，J3/J5 `±115.9°`，J4 `[-99,69]°`，J6 `±31.9°`，J7 `±72°`。它们仍需与当次真实硬件限位及现场净空核对。

train、val、test 必须分别真实录制，种子为 1701、2903、4307。种子改变任务姿态、逐关节起行方向与实际速度比例（在配置速度上限的 85%～100% 内），避免只验证固定轨迹的重复播放。实际到达速度还受 jerk 和路径限制，不保证每段都达到上限。

保留原有 C2 插值和连续窗口发送器：整套动作使用一条连续时间轴，窗口重叠，包含位置/速度/加速度；不再逐个短点发送并等待停车。静止段是有意设计的训练与验收动作，不是控制抖动。

大范围逐关节激励可能经过奇异姿态。这不妨碍学习关节外力矩；完整六维末端换算在这些时刻仍不可用。条件数筛选针对末端任务姿态及其连接、探测、联动、最终返回路径。初始接近允许从奇异姿态出发；不会为了显示曲线篡改奇异点判断。

## 整理与训练

编辑 `/home/venom/factr2/config/w3/right/baseline_campaign.example.yaml` 的三个目录，保存为自己的会话清单。原始数据不会修改；完整事件会成为独立 episode。静止块首尾各裁 1 s，动态块保留短路径和加减速段；历史窗口始终在单个 episode 内，不跨会话或跨角色。

断点恢复通过 `scripts/w3_baseline_resume.py` 离线生成剩余动作，而不是直接再次播放未完成快段。只复用原失败会话中已完整执行、实测覆盖合格且没有跨反馈中断的慢速逐关节动作。会话清单可以将训练来源写成 `{session: 原目录, events: [完整事件名, ...]}`，同时提供 `protocol_reference: {train: 完整参考计划, val: 完整参考计划, test: 完整参考计划}`。整理程序核对选中事件完成状态、原始 H5/标定/控制配置哈希，以及旧数据与补录数据的动作合集覆盖完整参考方案。验证和测试仍须独立完整录制；未完成的快段不会用于训练。

原始 H5 若因反馈超时分成多个 episode，整理时保留各段边界，不拼接成一条可跨越的历史序列。动态事件允许分别提取连续片段，但总实测时间覆盖至少 99.5%；静止验收窗口必须连续。更大的缺失、不足 50 帧的有效片段、未完成事件和实测幅度不足都会被拒绝。

recorder 的分段阈值也与质量检查对齐为两个采样周期：100 Hz 下超过 20 ms 就开新段，50 Hz 下仍为 40 ms。此前固定 40 ms 会让 100 Hz 数据里的 30 ms 缺口留在同一 episode，直到结束时才被质量检查拒绝。新实现不插值补帧；有效片段分开保存，质量和历史长度要求不变。每次录制审计目录会保存上述 adapter、recorder 和恢复脚本的源码哈希及副本。

恢复采集还修复了 adapter 的重复定时采样误报：在输入时间、收包时间、两流偏差和硬件健康都合格时，“这轮尚无新状态”只跳过输出，不作为硬件错误；不重复输出旧时间戳，真实超时与无效状态仍会停止运动。采集中不新建检查 ROS 节点，不读取仍在写入的 SQLite/H5。轨迹进程通过已有订阅每 10 s 在 `audit/motion_run.json` 写入 `live_monitor`（adapter 频率、当前角度、目标角度、最大跟踪误差），任务状态同步这些指标。检查工具或新 DDS participant 与一次 0.33 s 停更时间相近，确切停更原因尚未确认；采取上述方法减少检查对采集的干扰，而不放宽 250 ms 的反馈保护。

整理前还要求每个逐关节慢/快块的实测最小值、最大值覆盖配置范围的两端各 10% 以内。只显示“动作完成”而机械臂没动、或实测范围明显不足的录制会被拒绝。

```bash
cd /home/venom/factr2
scripts/next.sh python scripts/prepare_w3_baseline_campaign.py \
  --sessions /ABSOLUTE/PATH/baseline_campaign.yaml \
  --output /home/venom/factr2/data/right/BASELINE_CAMPAIGN_ID

scripts/next.sh python scripts/train_w3_baseline.py \
  --config /home/venom/factr2/data/right/BASELINE_CAMPAIGN_ID/train.yaml \
  --acceptance config/w3/right/baseline_acceptance.yaml
```

默认网络仍为 100 Hz、50 帧历史、stateless 两层 LSTM（128）加两层 MLP（256），输入 21 维、输出 7 个关节的无接触电机力矩。训练标签是实测电机力矩，**不是把无接触训练标签写成零**。外力矩才是实测减预测。

采用 AdamW、lr=1e-3、weight_decay=1e-6、梯度裁剪 1；最多 120 epoch，早停 patience=20、warmup=10、min_delta=1e-5。标准化仅由训练数据拟合；新方案的损失还原到物理单位 N·m 后计算 MSE，验证最优模型按这一损失选取。batch=256、CPU 8 线程是本机资源设置，不承诺论文的训练耗时。

同一原始会话或同一原始 H5 的派生片段不能跨 train/val/test；接触验证数据不能进入训练。参数内容不一致会拒绝训练。先看独立验证集，通过后才报告最终测试集；不要反复根据最终测试集调整阈值或选模型。

## 验收与显示

阈值文件为 `/home/venom/factr2/config/w3/right/baseline_acceptance.yaml`。以下是待现场确认的工程阈值，**不是论文在本机上的精度承诺**；必须在查看最终测试结果前冻结：

| 项目 | 初始门限 |
| --- | --- |
| 整体各关节 RMSE | ≤0.2 N·m |
| 静止各关节绝对均值 / 残差绝对值 P95 | ≤0.1 / 0.25 N·m |
| 同姿态双向返回、卸载前后基线差 | 各关节 ≤0.1 N·m |
| 卸载后均值、后半段与前半段漂移 | 各关节 ≤0.1 N·m |
| 空载末端均值 | 力各轴 ≤1 N；力矩各轴 ≤0.15 N·m |
| 空载末端绝对值 P95 | 力各轴 ≤3 N；力矩各轴 ≤0.4 N·m |
| 条件良好的末端路径几何有效率、静止末端换算有效率 | ≥99% |
| 接触响应 | 关节残差向量范数 P90 ≥0.5 N·m；至少 3 个不同 case |

还要求实测静止范围不超过 0.5°、速度不超过 0.04 rad/s；同姿态比较允许每关节最多 1.5°差异。末端验收采用与网页相同的阻尼换算、作用点和坐标轴，不把奇异或拟合不一致样本删掉后冒充全段合格。

输出 `baseline_acceptance.json` 分别列出验证、测试、卸载结果。未提供或未通过卸载验证时，训练脚本退出码为 1、`deployment_ready=false`，即使已经保存了训练候选；这表示尚未满足上线条件，不表示训练没有运行。也可在训练时附带 `--release-h5`、`--annotations` 一次完成整套验收。脚本始终不会自动修改当前推理配置或部署模型。

网页继续区分关节外力矩和末端等效六维力/力矩；后者假设接触发生在末端。多点接触、直接推连杆或内部误差不一定符合该假设。真正奇异位置必须保留“不可靠/不可用”提示；通过选择更好的工作姿态减少提示，而不是改变物理可观测性。用已知载荷或外部传感器才能额外验证接触量值与方向精度。

上线前需将候选模型报告、标准化文件、控制参数和训练清单一起保留，核对实际运行条件，通过后再更新推理配置和采集得到的工作范围。最新旧模型不自动删除；本次没有开始这一上线步骤。
