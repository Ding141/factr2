# 位置/速度反馈、求导不确定性与底层跟踪专项验证

本轮接在惯性对照之后：先前目标加速度 4/6/8°/s² 未在位置求导结果中稳定分离，不能继续把求导尖峰当作惯性因果证据。因此先检查反馈分辨率、运动学一致性、求导窗口敏感性，以及原生目标至驱动入口的跟踪。

结果目录：`log/next_feedback_trial_20261016_v2/`。`v1` 仅启动发现检查失败，未发送运动；保留失败记录，不覆盖、不续播。真实运行结果以 `v2/test_state.json`、`REPORT.md` 为准。

实机已完成62段、26次正式单程，原始CAN无接收丢帧；模型和控制参数未改变。离线分层核查发现：CAN至驱动发布的位置差至多约一个位置码（0.0219°），驱动发布至关节状态按原时间戳比较却出现最大约1.07°差异。350 Hz发布、300 Hz硬件read、KeepLast(50)及spin_some的组合应优先排查；下游重新打时间戳不能证明原始采样同步。另有接近半个速度码的基线偏差，以及在CAN层已经存在的脉动。详见结果目录的报告与三张图。

## 冻结方案

- 左臂保持原姿态，右臂在原训练范围内活动；起止静止各 15 秒，七关节安全探测后再静止 10 秒。
- 全七轴各走 2.4°，目标峰速 0.6°/s，双向分别标记；J1/J2/J4 再分别走 6°，目标峰速 1.2、2.4°/s。端点停留单独标记为 3 秒。
- 每段一次下发完整七相 S 曲线，保留内点速度和加速度；不由上位机逐小段插值下发。整段多项式限幅、训练范围、碰撞采样、实际跟踪和独立监护检查全部保留。
- 七轴探测为单独排除段；故意停留不混入连续运动。总共 62 段，纯指令时间 281.94 秒。
- 固定 100 Hz 三阶 SG11/21/31/51 和有限差分；平台前后各裁 0.25 秒，用位置位移和速度积分作不依赖求导的检验。
- 本批独立测试数据不参与延迟估计、模型训练或补偿调参。无时间平移搜索，跨层只匹配此前最近样本。

## 记录与解释边界

完整 bag 增加 `/w3_robot_bridge_node/commands`，保留 `/joint_states`、原生 `command_state`、adapter 四流和诊断。额外记录原始 CAN 内核接收时间、协议码及 NEXT 原始/滤波残差与末端力。

驱动关闭 `CAN_RAW_LOOPBACK`，所以不改变驱动配置时，旁路监听不能独立确认实际发送时刻；桥接输入的位宽量化重建不等于总线发送测量。CAN 内核接收时间也不等于电机采样时间。静止速度半码偏差需与位置跨度共同解释，不能直接宣布真实速度不为零。

SG 为离线居中滤波，会平滑短时真实动态；不同窗口的峰值范围属于方法敏感性，不能称为物理置信区间。位置与速度若共享同一内部估计器，彼此吻合仍不能代替外部编码器或测速器标定。
