## 录制同步修复

W3 adapter 给四路数据发布完全相同的时间戳。原录制端使用近似时间同步，单路消息丢失后可把相邻帧误配；严格帧检查随后持续报 `frame_stamp` 并分段。丢包回放测试复现了此问题。W3 现在使用精确时间同步；其他录制模式保留近似时间同步。不填补丢失数据、不插值时间戳。新的 H5 使用 128 行数据块以减少块索引增长，行内容和写入前检查保持相同。
